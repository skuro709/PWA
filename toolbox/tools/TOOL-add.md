# ツール追加・変更ガイド

SK TOOLBOX に新しいツールを追加したり、既存ツールの名前・ファイル名・アイコンを変更したりするときの手順書です。

## 1. 現在のファイル構成と役割

現在の実装では、ツールの表示情報と実際の実行処理は別々に管理されています。

| ファイル | 役割 |
|---|---|
| `data/tool-registry.js` | ツールID、表示名、カテゴリ、説明、検索語、アイコンなどを登録 |
| `assets/js/tool-runner.js` | ツールごとの入力欄と実行処理を定義 |
| `tools/<category>/<tool-id>/tool.js` | ツールごとのファイルを配置する場所 |
| `assets/js/app.js` | 画面表示、一覧、検索、アイコン描画、画面遷移 |
| `assets/icons/tool-symbols/` | ツールカードで使用するSVGアイコン |
| `sw.js` | オフライン用キャッシュの管理 |

**重要：現在の実装では、`tools/` 内の `tool.js` は `tool-runner.js` から自動的に読み込まれていません。**

そのため、ツールの実際の処理は `assets/js/tool-runner.js` に追加する必要があります。

---

## 2. 新しいツールを追加する手順

例として、`text-trim`（テキストの前後空白削除）を追加します。

### 手順1：ツールIDを決める

- 英小文字とハイフンを使用する
- 既存IDと重複させない
- カテゴリを先頭につけることを推奨

例：

`text-trim`

### 手順2：ツール用フォルダとファイルを作る

カテゴリに対応するフォルダを作成します。

```text
tools/
└── text/
    └── text-trim/
        └── tool.js
